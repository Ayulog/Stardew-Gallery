# 星露谷画廊需求说明

> 状态：v2 定稿，2026-11-16，适用于 2.10.0 之后的原生画廊体验升级版本。
>
> 依据：1.0.0 的最初定位、2.0–2.10.0 的演进基线，以及 2026-11-16 用户确认的“原生画廊体验”升级取舍（见第 8 节与附录 A）。
>
> 本文是当前需求的唯一依据。`docs/` 中的阶段文档、版本说明和调研只保留为历史记录，不再作为范围或承诺。

## 1. 定位

**星露谷画廊是一本融入游戏原生体验的村民回忆手账与剧场鉴赏相册。** 它做四件事：

- 以统一的皮质手账书本与自动定格剧照，按角色珍藏当前生效的好感故事与婚礼纪念。
- 无需切出游戏查外部资料，直观告诉玩家未触发故事还差哪些条件、哪些故事“今日即可偶遇”。
- 在绝对不改变真实存档进度的沙盒中，让玩家安全重温看过的故事、定格取景，并体验单周目因互斥选择而错过的分支与平行路线（If 线）。
- 只读追溯事件、分支子脚本与前置标记的模组来源，方便整合包排查出处与冲突。

## 2. 使用场景

| 场景 | 玩家想做的事 | 对应功能 |
| --- | --- | --- |
| 珍藏与翻阅 | 像翻实体纪念册一样回顾经历过的故事与婚礼瞬间，收藏最爱片段、导出剧照 | 皮质手账三书签、自动回忆定格、婚礼留念卡、台词签注、珍藏时刻、打开本地目录 |
| 重温与分支鉴赏 | 再看一遍喜欢的剧情，或看看当年选另一条分支会怎样，定格挑一张好构图当封面 | 安全回放、剧场控制（倍速 / 暂停隐框取景 / BGM 曲名）、本事件选项重选、`fork` 路线切换、平行分支（If 线） |
| 偶遇与补全 | 弄清某段故事为什么没触发、今天镇上有哪些故事可以去偶遇、前置是哪个 | 双级“可偶遇”线索、1.6 原生 GSQ 条件清单、多级前置跳转、故事索引 |
| 查问题 | 某段剧情、分支或前置标记来自哪个 Mod、定义在哪个文件 | 事件与前置静态来源、其他声明者 |

## 3. 设计原则（硬性约束）

1. **存档安全第一。** 画廊的任何浏览、自动留影、普通回放或分支 / 平行路线鉴赏，都绝不能改变真实存档进度。做不到时，宁可不回放或不切换演出环境。
2. **只读分析。** 条件、偶遇线索与来源分析都是只读的：
   - 不执行触发器动作。
   - 不调用注册的第三方条件委托或消费随机状态。
   - 不改变真实已看状态、好感度、信件或回答记录。
   - 判断不了的如实标为“未知”；含未知条件时绝不误报为“可偶遇”。
   - 与游戏 1.6.15 实际判定不一致视为缺陷。
3. **离线。** 完全不联网。
4. **不干预其他 Mod 与存档资产。**
   - 不补丁 SMAPI 或其他 Mod 的内部实现。
   - 回放期间的保护与分支路由拦截只作用于画廊自己发起的回放事件实例。
   - 不改写游戏文件和其他 Mod 的资源，不向游戏注入自定义家具等存档实体资产。
5. **基于当前已加载内容与受控回放沙盒。**
   - 目录和回放都基于当前存档与当前已加载生效的游戏资产，不做历史冻结版本，也不拼装未激活的 Content Patcher `When` 补丁。
   - 回放内重现本事件已答提问或指定 `fork` 子分支，严格限制在本次回放作用域内生效，结束后必须完整恢复真实状态。
6. **保留玩家数据。** `config.json`、`event-photos/`、`user-data/`（自定义名称与喜爱标记）在升级中保留并保持向后兼容。
7. **可选依赖可回退。** GMCM、Portraiture、DDFC、Scale Up、HD Portraits 缺失或读取失败时，基础画廊照常可用。

## 4. 功能需求

“核心”是产品存在的理由，“辅助”服务于核心。

### 4.1 皮质手账架构与三书签导航（核心）

- **统一书本视觉**：全流程统一承载于摊开的皮质手账大书（逻辑画布 `1672×941`）中，前置详情、剧照管理、改名小浮窗与筛选下拉浮层均统一为皮质手账视觉，取消脱离书本风格的独立黄色大弹窗。
- **左下彩色书签（Tabs）**：书本左下设三枚长短双态像素书签切换章节（切换到“故事索引”或“珍藏时刻”时栈底保留“村民相册”首页，按返回先回到首页再关闭画廊）：
  1. **村民相册**：角色陈列首页与角色个人好感相册。
  2. **故事索引**：原“事件查询”书本化双页重排（左页搜索与书页内嵌筛选下拉浮层，右页故事条目）。
  3. **珍藏时刻**：跨角色展示玩家标为“喜爱”的故事卡片及当前存档的婚礼留念卡。
- **拟真翻页交互**：
  - 村民陈列网格与角色相册卡片采用左右整页翻书交互（底部显示页码与折角翻页箭头，支持鼠标点击、滚轮与手柄肩键翻页，配原生翻书音效），取代主书页上的垂直滚动条。
  - 仅详情页长条件清单与来源详情段落保留局部滚动条。

### 4.2 村民相册、卡片视觉与收集生命力（核心）

- **收录与去重**：
  - 带有明确正向好感关系条件的剧情（含心数、好感点数、约会、配偶、室友及对应 GSQ 写法、多角色门槛）及可信续篇，归入对应角色相册。
  - 普通剧情和前置事件不进个人相册（在“故事索引”查看）。
  - 游戏原生复制到多地点的同一剧情（如爷爷评价、`Trailer` 与 `Trailer_Big`）只收录一次，保留真实身份（资产 + ID），旧版重复条目上的剧照与名称自动并入。
- **角色归并**：使用当前游戏中的角色名称与生效外观，已核实的角色别名和分身合并为一人。
- **村民陈列（首页）**：
  - 角色搜索框（中文界面支持全拼、首字母与混合拼音）、“一键解锁全部 / 恢复锁定”。
  - **收集进度与满收集金星**：每位已认识角色头像下方显示清晰的 `已收 / 总数` 故事进度（不再使用易与好感心数混淆的 `❤️ 数量`）；当该角色所有故事节点均已收集完成时，点亮**星露谷原生金色星星徽章**。
  - **单周目友好的进度统计口径**：因前序互斥条件导致单周目只能触发其一的平行互斥事件组，在收集统计中算作**同一个故事节点**（真实经历其中任一条即视为该节点已完成，不让正常单周目玩家卡在 `N-1 / N` 无法获得金星）；婚礼留念卡作为额外纪念，不计入未婚角色的分母。
- **角色个人相册（左页档案与动态景窗）**：
  - **四季昼夜动态景窗与草地自然漫步**：左侧角色展示窗背景随当前游戏的春/夏/秋/冬、昼夜光线与天气自然变化；标准 4×4 行走图角色小人在草地平坦区内做**平缓左右漫步（真实四帧行走）+ 自然驻足面向玩家待机**循环（不做生硬原地四向机械转圈；非标准精灵表安全回退第 0 帧静止）。
  - 显示角色名称、心数槽、生日、本周与今日送礼、今日是否对话、故事进度与当前关系状态。
- **故事卡片命名与台词签注（祛除裸 ID）**：
  - 未设置自定义名称时，卡片默认标题显示为 `心数 · 发生地点`（无固定心数门槛时显示关系阶段与地点；普通故事显示 `普通故事 · 发生地点`）；自定义名称优先显示。
  - 原始 `EventId` 从卡片主标题移至详情页副信息栏（搜索框依然支持按 `EventId` 精确或模糊搜索）。
  - **代表台词签注**：对已真实经历、已开放的平行分支（If 线）或已开启“一键解锁”的故事，自动静态提取主角在该事件中的第一句有效对白（剥离 `$h` / `$s` / `$b` 等控制符），用于详情页手账引语与卡片悬停提示；**未看且未解锁的故事严格隐藏台词，防止剧透**。
- **差异化拍立得卡面**：
  - 已有剧照封面的故事显示实景封面。
  - 尚无剧照封面且未真实经历的故事（含已开启“一键解锁”但未真实看过的故事）统一采用**火漆信封 / 拍立得背面**视觉样式，胶囊签明确区分“未观看”与“未解锁”，告别千篇一律的默认山水占位图。
- **双级“可偶遇”故事线索与画廊外轻联动**：
  - **今日可偶遇（醒目金标）**：某段未看故事的长期条件（好感、已看前置、信件、年份、房屋等级、配方/物品等）已全部满足，且当日季节、星期与事件地点天气均吻合（仅差当日时间段与前往现场）时，在首页角色头像与对应卡片上点亮“今日可偶遇”金标。
  - **线索就绪（柔和角标）**：长期条件已全部满足，仅等待合适的季节、星期或天气。
  - 条件中含有任何“未知”项时，不提示为可偶遇。
  - **每日清晨手账轻提示（`ShowMorningEncounterHint`，默认开启，可在 GMCM 关闭）**：每日起床时只读扫描当前存档已结识村民的好感故事，若存在 `AvailableToday` 的未看故事，左下角弹一条无剧透原版 `HUDMessage` 提示今日可偶遇的角色姓名（人多时截断为“XX、YY 等 N 位村民”）。
  - **原版 `E` 菜单「社交（❤️）」页偶遇角标（`ShowSocialPageClueBadges`，默认开启，可在 GMCM 关闭）**：浏览原版 `SocialPage` 时，在拥有今日可偶遇（金章 `!`）或线索就绪（绿叶章）的已结识村民行旁绘制像素徽章（按天/地点/菜单状态轻量缓存，不向原版控件列表硬塞组件），悬停显示不剧透提示与按键说明，左键点击徽章直接打开该村民相册并在退出时恢复原社交页位置。
- **一键解锁与缓存刷新**：
  - 一键解锁只影响画廊内的查看和回放权限，绝不修改真实进度；按存档保存（联机农场工仅在本次会话生效且不报错）。
  - 读档、返回标题、切换语言、事件或角色数据变化后自动更新目录，打开画廊不每次全量重建。

### 4.3 剧情详情、1.6 原生 GSQ 解析与前置跳转（核心）

- **显示内容**：
  - 标题、自定义改名按钮、喜爱标星开关。
  - 副信息栏：事件 ID、发生地点、过场配乐（BGM）可读曲名、事件来源（见 4.7）。
  - 代表台词签注（仅已看 / 已解锁显示）、封面缩略图（点击进入剧照管理）。
  - 同事件分支路线选择器（仅当事件含可切换 `fork` 子分支且当前可回放时显示）。
  - 条件清单与回放按钮。
- **条件清单与 1.6.15 判定对齐**：
  - 每条写明要求和当前状态：满足、未满足或未知；未知需说明原因（如随机结果、第三方条件、需要实时环境）。
  - 覆盖 41 种原版传统前置条件（含原版特殊语义，如 `Season` 多参数只检查首个季节并注明被忽略的季节、`D` 涵盖订婚与已婚、`R` 含待入住室友、`a X Y` 明确展示入口格坐标 `(X, Y)`）。
  - **系统扩充原版 1.6.15 纯只读确定性 GSQ 白名单（支持合法带引号参数与递归 `ANY` / `!ANY` 复合子句）**：覆盖 `ANY` / `!ANY`（三值逻辑对齐 1.6 `DefaultResolvers.ANY` 并提取子句内 `PLAYER_HAS_SEEN_EVENT` 前置跳转）、日期/时间/季节（`SEASON`、`LOCATION_SEASON`、`SEASON_DAY`、`YEAR`、`DAY_OF_MONTH`、`DAY_OF_WEEK`、`TIME`、`DAYS_PLAYED`）、天气与绿雨/节日/姜岛日程（`WEATHER`、`IS_GREEN_RAIN_DAY`、`IS_FESTIVAL_DAY`、`IS_PASSIVE_FESTIVAL_TODAY`、`IS_VISITING_ISLAND`）、世界与路线进度（`WORLD_STATE_ID`、`BUILDINGS_CONSTRUCTED`、`IS_COMMUNITY_CENTER_COMPLETE`、`IS_JOJA_MART_COMPLETE`、`IS_ISLAND_NORTH_BRIDGE_FIXED`、`FOUND_ALL_LOST_BOOKS`、`MUSEUM_DONATIONS`、`MINE_LOWEST_LEVEL_REACHED`、`IS_MULTIPLAYER`、`IS_HOST`）、玩家属性与进度（金钱、性别、各技能等级、农舍等级 `PLAYER_FARMHOUSE_UPGRADE`、结识村民 `PLAYER_HAS_MET`、宠物 `PLAYER_HAS_PET`、子女 `PLAYER_HAS_CHILDREN`、小镇钥匙 `PLAYER_HAS_TOWN_KEY`、特别任务 `PLAYER_SPECIAL_ORDER_COMPLETE` / `ACTIVE`、已听曲目 `PLAYER_HAS_HEARD_SONG`、讨伐怪物 `PLAYER_KILLED_MONSTERS`、持有物品、制造/烹饪配方、成就、秘密纸条、已访地点、好感/关系、已看事件、信件、对话主题、已运行触发器、`PLAYER_HAS_DIALOGUE_ANSWER`、统计值等）。
  - 随机类（如 `RANDOM`）与第三方自定义 GSQ 不执行外部委托，统一标为未知。
  - 所有受支持条件与内置 GSQ 必须通过运行时对拍检查验证与游戏 1.6.15 原生判定一致。
- **前置跳转与前置资料**：
  - 条件中正向引用的前置事件可点击多级跳转，并支持按原路径和滚动位置逐级返回；否定引用（要求“未看过”）只作参考链接不算前置依赖。
  - `Data/TriggerActions` 等前置事件资料只读展示触发时机、获得状态、条件、关联故事及**静态来源提供者**，不提供回放。

### 4.4 安全回放、剧场控制与分支鉴赏（核心）

**可以回放的范围**

- **好感剧情**：已在存档中真实经历过，或属于**已开放的平行互斥分支（If 线）**，或已开启“一键解锁全部”。
- **平行互斥分支（If 线）开放规则**：
  - 针对当前已加载进 `Data/Events` 的同一角色好感事件，若两条或多条事件具有明确互斥前置（如依赖同一前序提问的不同回答 `ChoseDialogueAnswers` / `PLAYER_HAS_DIALOGUE_ANSWER`，或显式正反互斥 `SawEvent`），当玩家已在存档中真实经历过其中一条路线时，同组错过的平行路线自动标为“平行分支（If 线）”并在画廊中开放回放鉴赏，无需开启全局一键解锁。
  - 鉴赏平行分支绝不将其写入真实存档的 `eventsSeen`。
- **普通剧情**：GMCM 中开启“普通剧情回放”（默认关闭），且已看过或已一键解锁。
- **不可回放**：前置事件、内部流程、婚礼留念卡。
- **联机限制**：回放仅支持单人。网络联机、本地分屏以及以联机模式运行的存档（含房主独自在线）均只可浏览画廊，不可回放。

**存档安全（最高优先级）**

回放无论自然结束、跳过还是启动/演出失败，结束后以下状态必须与回放前一致：

- 位置与朝向、时间、季节与天气状态。
- 金钱与收入统计、成就。
- 好感、已看事件、信件、任务、对话回答记录（`dialogueQuestionsAnswered`）、对话主题、配方、技能经验。
- 背包物品的完整引用与属性（包括鱼竿上的鱼饵和钓具、弹弓弹药）。
- Buff、已听歌曲、已访问地点、已运行 TriggerAction、事件地点壁炉开关。
- 地图上的作物、肥料、果实和采集物。

其他安全要求：

- 回放期间禁止保存，并在回放前自动备份当前存档（正常结束后清理本次临时备份，仅当恢复玩家状态本身失败时才退回最近存档并保留最近两份旧备份）。
- 回放过程中不得启动或结束真实节日、真实事件或触发器动作；回放结束后自动串联的后续事件必须拦截且不标记为已看。
- 新存档第一次睡觉前尚无存档文件时，明确提示原因；第三方自定义事件命令对外部文件或私有状态的修改不在原版快照回滚保证内，需如实告知。

**演出环境与沙盒分支控制**

- **演出环境（含正向 GSQ 提取）**：
  - 从旧式 `Season` / `Time` / `Weather` 前置以及正向 GSQ 条件（`WEATHER`、`SEASON`、`LOCATION_SEASON`、`SEASON_DAY`、`TIME`）中提取所需的季节画面、时间与原版天气；当前环境已满足时保持不变，否则采用首个受支持的原版环境值。
  - 季节切换只改变当前事件地点的贴图与光色表现，绝不调用全局换季更新。
- **本事件内已答 `$q` 选项重现**：
  - 回放期间，对当前回放事件及其分支子脚本中明确声明的非 `-1` 内联 `` `$q` `` 响应 ID 做临时内存遮蔽，使玩家已回答过的当场提问可重新弹出选项；保留其他前序事件的回答 ID 以维持跨事件剧情连贯，回放结束由快照完整恢复。
- **同事件 `fork` 路线切换**：
  - 对包含明确 `fork <条件ID> <子键>` 的可回放事件，详情页提供分支路线选择（默认“跟随当前存档”，也可指定进入某条子路线），仅在画廊回放事件自身的 `Fork` 分发处生效，不篡改真实存档信件或标记。

**剧场鉴赏控制（Theater Controls）**

- **倍速与自动推进**：支持 `1x / 2x / 4x` 倍速切换；可选对话自动推进仅在 `2x / 4x` 下生效，遇到玩家选项时自动停下等待选择。
- **自动淡出 HUD**：回放期间若干秒无鼠标移动或控制键输入后，右上角控制条平滑淡出以保持画面纯净，有输入时立即恢复。
- **暂停与隐藏对话框定格取景**：提供快捷键与屏幕按钮，一键暂停事件推进并隐藏对话框与控制条，供玩家欣赏场景细节与从容抓拍剧照，再次触发即恢复播放。
- **配乐（BGM）曲名显示**：在回放控制区与详情页展示当前事件配乐的可读名称。
- **失焦保护**：超时仅按游戏实际推进帧累计，窗口失焦或暂停不计入超时。

### 4.5 自动回忆定格、婚礼留念与剧照管理（核心体验）

- **静默自动留影（Auto-Memento）**：
  - 当玩家在正常游玩（含单人、联机与分屏本地客户端）自然触发已收录剧情，或在单人回放尚无封面的已收录剧情时，待黑屏淡入完成且进入可见稳定舞台帧后，在 `DialogueBox` 与 HUD 绘制之前的世界渲染层**自动静默抓拍首张无 UI 剧照设为初始封面**。
  - 自然游玩触发的自动留影不播放快门音效、不弹出打扰剧情的提示横幅；可在 GMCM 关闭“自动定格回忆剧照”（默认开启）。
- **手动纯净抓拍**：
  - 回放途中可通过快捷键（默认 `F8` / `LB`）或屏幕相机按钮随时抓拍不含 HUD、对话框和跳过按钮的剧照（含默认 100% 在内的任意缩放比例均有效），保留快门音效与提示。
- **配偶相册“婚礼留念卡”**：
  - 玩家举办婚礼时，在婚礼场景稳定帧自动静默抓拍，生成带游戏内结婚日期（年份、季节、日）的专属“婚礼留念”卡片，展示于对应配偶相册首位与“珍藏时刻”书签中。
  - 婚礼留念卡支持看大图、管理多张照片与恢复/移除，**不提供事件状态机回放**。
- **保存、管理与导出定位**：
  - 照片按存档分别保存于 `event-photos/`，可设为封面、恢复默认、移除（移入归档，不物理删除）；写入失败需提示且不留无主残片。
  - 剧照管理页显示本地文件夹路径，并在桌面系统提供 **“打开本地文件夹”** 按钮（Steam Deck 游戏模式或不支持调起文件管理器的环境下优雅降级为仅展示路径）。

### 4.6 故事索引、珍藏时刻与自定义名称（辅助）

- **故事索引（第 2 书签）**：
  - 覆盖好感剧情、普通剧情与前置事件（纯过场转换与内部流程不展示）；查询结果不计入相册收藏统计。
  - 搜索支持自定义名称、默认标题、事件 ID、角色、地点、来源 Mod 名称或 ID，中文界面下支持全拼、首字母与混合拼音检索。
  - 左页筛选包含：类型、角色、地点、来源、完成进度（已看 / 未看），点击任一行均弹出**书页内嵌手账下拉列表浮层**（首项固定“不限”，候选项较多时自带拼音/关键字搜索框），以及底部**“可偶遇”快捷筛选**（筛选今日可偶遇或长期条件已就绪的未看故事）。
- **珍藏时刻（第 3 书签）与喜爱标记**：
  - 详情页可切换故事的“喜爱”状态，与自定义事件名称一并按事件身份（资产 + ID）原子保存于 `user-data/`（本机存档共用，损坏自动回退最近备份，备份上限 5 份）。
  - 集中陈列所有喜爱故事及当前存档婚礼留念，方便一键重温。

### 4.7 事件与前置静态来源（辅助，用于查问题）

- **识别与展示**：
  - 详情页只读显示事件的原始提供者（原版 XNB，或具体 Content Patcher / AliveNpcs 包的名称、ID、版本与定义文件），同时单独列出“其他声明者（不一定在当前存档生效）”；原包未能完整读取时明确提示“证据不完整”。
  - **`Data/TriggerActions` 前置提供者**：静态扫描声明该前置规则的原始包与其他声明者，在前置详情页展示。
  - **`fork` / `switchEvent` 分支子脚本来源**：当事件的分支子键在事件资产中被声明或被其他包单独覆盖时，在来源详情中补充列出对应分支声明者。
- **跨平台与边界**：Windows、Linux（Steam Deck）、macOS 结果一致，兼容大小写差异与 Stardrop 等链接目录部署；纯 C# 或其他框架标为“未知”；来源仅用于显示与检索，绝不影响收录、解锁与回放。

### 4.8 相册外观兼容（辅助）

- 首页和相册显示角色当前生效的肖像与小人。
- 只读兼容普通 Content Patcher、`Portraiture`、`DDFC`、`Scale Up Unofficial` 以及 **`HD Portraits`（公开虚拟资产 `Mods/HDPortraits` 的帧尺寸与动画配置）**。
- 读取失败时先回退到普通肖像，最后才用占位图标，日志限频；回放画面中的角色外观完全由游戏与已装美化 Mod 决定，画廊不干预。

### 4.9 操作、入口联动与语言

- **三种原生入口**：
  1. 快捷键（默认 `G`）。
  2. 游戏菜单“收藏”页侧边的画廊按钮。
  3. **原版菜单“社交（Social）”页上下文直达与偶遇角标**：当玩家在原版“社交”列表悬停或用手柄选中某位村民行时按下画廊快捷键，或开启 `ShowSocialPageClueBadges` 时左键点击村民行旁的偶遇像素徽章，直接打开该村民的个人相册页（绝不向原版社交页控件列表硬塞额外组件以免与其他 UI 美化冲突），按返回键退回原社交页滚动位置。
- **手柄、Steam Deck 与键鼠同等可用**：
  - 所有书签、翻页、分支选择、剧照管理与工具页均支持方向键 / 摇杆移动焦点，`A` 确认，`B` 返回上一级，肩键翻页或滚动。
  - 兼容“吸附菜单”开与关，键鼠与手柄随时切换不丢焦点、不重复触发。
  - 手柄进入输入框时优先调起 Steam 屏幕键盘（支持中文），不可用时回退游戏键盘配合拼音搜索；实体键盘打字通过游戏原生 `IgnoreKeys` 隔离快捷键，不补丁 SMAPI。
- **语言与适配**：内置游戏官方全部 12 种语言，自适应不同分辨率与 UI 缩放，长文本省略并在悬停或聚焦时展示全文。

## 5. 明确不做

- **内容隐藏与过滤**：AI Mod Exclusion 名单，以及任何按名单或来源隐藏、限制内容的功能；运行时修改追踪（补丁 SMAPI 内部实现）。
- **外观切换与未激活补丁拼装**：回放时强行使用原版外观、选择美化 Profile、Gallery Profile 重启切换模组，或脱离 Content Patcher 强行拼装当前未满足 `When` 条件的补丁分支。
- **高风险回放与进度篡改**：
  - 联机与分屏回放。
  - 历史冻结版本回放。
  - 对未满足条件的锁定剧情做全局玩家状态注入式“预览”，或做“一键传送到事件现场 / 强制在真实世界触发并写入存档”的功能。
  - 节日主流程、婚礼仪式、夜间 `FarmEvent`、电影放映的状态机重跑回放（婚礼仅支持发生当下静默抓拍生成纪念卡，不做状态机回放）及纯 C# 自定义事件。
- **重度外部耦合**：向游戏注入自定义农舍家具资产（`Data/Furniture`）、接入外部工具栏图标框架（Iconic Framework），或路线规划求解器。

## 6. 兼容与质量要求

- **版本与平台**：游戏 1.6.15+、SMAPI 4.5.2+、目标框架 `net6.0`；支持 Windows、Linux / Steam Deck、macOS。
- **性能**：大型整合包（约 1,000 个事件）下打开画廊、切换书签与翻页无明显卡顿；目录、条件线索与静态来源扫描缓存复用，仅在相关内容或状态变化时增量或按需更新；自然游玩自动留影不得造成明显掉帧。
- **自动验证**：
  - `Checks`（覆盖目录分类、互斥平行分支识别、偶遇线索分级、书签/翻页导航、静态来源含 `TriggerActions` 与分支子脚本、`HD Portraits` 外观区域计算）与 `PersistenceChecks`（照片、婚礼留念卡、自定义名称与喜爱标记存储兼容与损坏恢复）。
  - SMAPI 运行时检查覆盖回放快照、GSQ 环境提取、本事件 `$q` 重现恢复、`fork` 路线分发、内置 GSQ 与游戏 1.6.15 对拍、手柄导航及全缩放比例截图。
- **实机验收**：每次发布前按清单验证自然游玩静默留影、婚礼留念、普通回放与分支 / If 线鉴赏、暂停隐框取景、Steam Deck 手柄及 12 种语言排版。

## 8. 已确认的升级取舍（2026-11-16）

1. **打破工具感，全面向原生回忆手账靠拢**：取消脱离皮面书的独立查询大表格，通过三枚侧边书签统一“村民相册 / 故事索引 / 珍藏时刻”，主视图采用整页拟真翻书，裸 `EventId` 退居详情页，用“心数 · 地点”与防剧透首句对白签注唤醒剧情记忆。
2. **自然游玩静默自动留影 + 婚礼留念卡**：解决相册满屏默认山水占位图的问题；婚礼采用“发生时自动留影存入配偶相册、不做高风险状态机重跑回放、不计入未婚分母”的安全纪念方案。
3. **单周目分支与平行路线（If 线）鉴赏**：覆盖本事件已答 `$q` 选项重选、同事件 `fork` 路线手动切换，以及已经历其中一条后的同角色互斥平行事件（If 线）开放鉴赏（互斥组在收集统计中算同一节点，不卡单周目满收集金星）；不拼装未激活的 Content Patcher 补丁。
4. **1.6 原生 GSQ 全量只读扩充 + 回放环境提取**：系统覆盖原版 1.6.15 纯只读确定性 GSQ（含带引号参数）并与游戏对拍，回放环境同步支持从正向 GSQ 提取季节画面、时间与原版天气。
5. **双级“可偶遇”线索替代繁琐多维筛选**：不恢复旧版复杂的五维条件交叉筛选框，改用“今日可偶遇 / 线索就绪”双级徽章与故事索引中的单一“可偶遇”快捷筛选。
6. **轻量外围闭环，拒绝存档资产污染**：补齐 `TriggerActions` 与分支子脚本静态来源、原版“社交”页快捷键上下文直达、剧照目录一键打开与 `HD Portraits` 只读兼容；不做自定义农舍家具资产注入与外部工具栏框架耦合。
