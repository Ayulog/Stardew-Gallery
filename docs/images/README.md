# README 宣传素材 / README media

这四张截图由项目维护者提供，保留原图内容及 1280×720 尺寸，用于展示实际游戏界面。截图中的角色与事件取决于游戏安装的内容和外观模组，不作为所有模组组合的兼容性证明。

| 文件 | 内容 |
| --- | --- |
| `gallery-overview.png` | 角色画廊与剧情数量 |
| `character-album.png` | 好感相册、角色资料与事件卡片 |
| `event-details.png` | 条件、来源和满足状态 |
| `event-query.png` | 事件搜索、筛选入口与来源提示 |

The screenshots are supplied by the project maintainer and retain their original 1280×720 contents. Game and third-party artwork visible in these screenshots belongs to its respective creators; the underlying mods and reusable artwork are not distributed with the screenshots.
