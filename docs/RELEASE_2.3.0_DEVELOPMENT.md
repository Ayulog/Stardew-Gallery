# 2.3.0 Delta：前置事件与搜索直达

基线：2.2.0 `e4627fd`。分支 `feature/2.3.0-event-navigation`。用户已授权截图完成后连续开发，最后一起验收。

- 详情从结构化 SawEventCondition.EventIds 增加独立 ID 链接，不解析翻译文案，不改 ANY/否定或求值。每个 ID 独立选择；同 ID 多资产展示来源供选择，当前目录缺失时明确提示。
- 仅消费当前 GalleryCatalog.Events；不探查隐藏定义，不改 candidate/current 选择。不依赖事件 ID 猜测变体，按选定 EventIdentity 打开。
- 详情跳转保存整层菜单的条件滚动和焦点；循环回到现有祖先，返回逐级恢复。目标未解锁可看详情，回放仍按既有 seen/unlock 权限。
- 首页保留人物搜索和排序；增加“查找事件”按钮，输入后 Enter 也可直达事件。检索当前事件 ID、角色内部/显示名、地点内部/可读名；不新增条件解析搜索。单结果直达，多结果列表选择，返回保留列表/首页查询和位置。
- 鼠标、键盘与手柄均可选链接和列表；12 locale 适配，复用截图版本的封面与原版控件。条件和回放仅复用已有 helper/API，历史/存档保持不变。

验收：单/多/缺失 ID、大小写与跨资产区分、锁定目标、跨角色、多层返回和循环；搜索各字段、部分匹配、无结果和正确身份；自动 focused checks、build、12 locale 截图及交互验证。玩家稍后与 2.2.0 合并实测。
