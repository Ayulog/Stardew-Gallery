# 2.10.0 实机验收清单

2026-10-21 整理。下列场景都已有离线检查（`tools/Verify-Local.ps1`），但没有在真实游戏里跑过；发布前逐项实测，把结果、存档、SMAPI 日志位置记在每项后面。通用步骤沿用 [RELEASE_2.5.0_STORY_TESTING.md](RELEASE_2.5.0_STORY_TESTING.md) 第 1–6 项。

- **环境**：Stardew Valley 1.6.15、SMAPI 4.5.2，使用测试存档或存档副本。
- **日志**：`%AppData%/StardewValley/ErrorLogs/SMAPI-latest.txt`。
- **安装**：干净的 `Mods/StardewGallery` 文件夹，拷回 `config.json`、`event-photos/`、`user-data/`。

| 3.9 | 中文界面：首页搜索 `abge`、`abigaier`；查询页按某个地点或事件名称的拼音首字母搜索 | 找到阿比盖尔和对应事件；切到英文界面后拼音不生效，英文名照常可搜 |

| 3.11 | 开启 GMCM“调试诊断”，在画廊各页操作半分钟后查看 SMAPI 日志 | 每 5 秒一条“画廊帧耗时”；记下数值，更新和绘制的平均耗时应明显低于 16 ms（60 帧的单帧预算） |
| 3.12 | 实体键盘在搜索框里打出绑定了快捷键的字母（画廊的 `G`、其他 Mod 绑在字母上的键），再按 F1、F3 | 只输入文字，快捷键都不触发；Ctrl+V 粘贴一次；Esc 退出输入而不关画廊；离开输入框并松键后快捷键恢复 |
