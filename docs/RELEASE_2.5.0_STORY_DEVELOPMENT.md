# 2.5.0 Delta：好感剧情相册与自助查询

基线v2.4.0 `6e61669`。2026-09-09用户批准按重新确认需求开工；本分支`feature/2.5.0-story-gallery`从基线重新实现，废弃版本不作为开发起点。

- 好感剧情进入主相册与查询器；完整普通剧情只在查询器；纯转场/发信/标记流程不作为事件展示或回放，但后台可解释它们对应的前置状态。
- 查询支持ID、NPC、地点及前置定位。首页沿用既有相册和一键解锁，增加独立查询入口。查询结果不自动计入收藏。
- 普通剧情回放默认关闭，由GMCM单独开启；未经历剧情仍需原一键解锁。好感/普通共用一套权限、播放与恢复，不以社交NPC归属直接判定可否执行。
- 短剧情不按时长/命令数裁掉。根据脚本整体的叙事证据与内部流程特征分类，结合已有样本验证；复杂或有作者扩展的场景不得仅因未知命令自动当作内部流程。
- 模块分别负责事件资料、条件依赖、相册/查询视图、回放、照片及导航。共用绘图从首页移出，页面间不读私有数据；导航保存明确页面状态，不嵌套菜单返回回调。入口只接线。
- 修复本轮涉及的2.4条件详情状态遗漏、同名实例定位，以及金钱统计/任务/动画状态恢复缺口。保留配置、照片、存档身份和12语言支持，不改变最低游戏/SMAPI版本。

验证：剧情分类样本与模块接口focused checks；统一权限组合与内部流程不可见；前置/返回/搜索；回放生命周期/保存保护/恢复隔离运行；存储总入口；12locale+生产UI截图。正式实机无法完成时只交付待实测开发包，不发布main/release。

本次分工按文件所有权：事件资料及分类、回放修复、菜单与绘图独立实现，主代理完成共享接口、导航/入口整合、条件依赖、配置翻译、最终验证与交付。

## 完成实现与验证

- 模块独立维护入口见`MODULES.md`。唯一菜单创建入口为`GalleryApplication`，页面状态由`GalleryPageHistory`保存；删除导航中的旧回放资格判断，页面共用`ReplayAccessPolicy`。共用图形方法在`GalleryDrawing`，详情不再向角色菜单取数据。
- 分类复用已有ConditionParser；明确正向Friendship/Dating/Spouse证据及可信续篇为Heart，纯内部状态与转场/等待结束为Internal，其余保留Ordinary。短表情和无对白动作剧情不会按时长或命令数裁掉。未知命令或片段缺失不据此断言无剧情。
- 同一已有1725来源身份快照：704 Heart、999 Ordinary、22 Internal，92个可用相册角色，7个内部前置来源链接；不同资产的同ID仍是不同来源，不能把这些数当独立剧情数量。难判的声音收尾/订单剧情暂留Ordinary，未新增无证据硬编码覆盖。
- 内部前置只在原条件下解释解锁步骤、地点和该步骤条件，不生成独立事件项、点击目标或播放入口。原始记录保留用于解释，不改真实已看状态。
- Checks PASS：60个分类场景、统一权限组合、自助查询/来源定位、内部步骤、页面状态循环/失败回退及现有回归；12locale键和占位符保持一致。PersistenceChecks PASS，历史/照片schema未改变。
- 回放模块11项独立游戏程序集检查通过，覆盖Money/累计与个人收入/成就、Quest网络字段深层状态与通知、动画/像素位置恢复、唯一地点请求、异步调度/过期回调和回放会话身份、保存保护。邮件标记到fork的原生分支及临时话题行为通过，不用阻止临时标记改变剧情分支。
- 回放使用isMemory、已知后果拦截和恢复，未设置可播放命令白名单。陌生命令仍交原框架执行；部分原版结算、onEventFinished和特殊结束/跳过行为被省略。nativeAction、LocationSpecificCommand、Cutscene、第三方私有数据/外部文件和任意回调未能提供完整恢复保证，既有回放确认文案已明确范围。不能宣称任意脚本都无副作用。
- 第一轮生产UI隔离验证82项行为与10张非空截图通过，12语言检查发现字体心形、韩文分隔符和长资料装饰间距问题，已分别改为纹理图标、语言适配分隔符、40像素文字留白；后续仅复测这些修改与内部前置说明。
- 显示修正的150项定向复测通过：12语言字形/边距、4张修正图及内部步骤说明；长内部条件内容在裁剪区滚动，返回保留位置，内部链接始终不可点击且不写已看记录。新增步骤说明中的比较字符另统一为ASCII写法，避免游戏字体将其显示为星号。
