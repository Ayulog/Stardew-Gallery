# 2.5.0 Delta：普通事件目录与内容补采

基线 `6e61669`（2.4.0）。用户授权一、二阶段同时开发，普通事件优先关联 NPC。

- 展示关联与原有回放归属分开。明确好感对象、实际发言 NPC 可关联，多人剧情可在多个相册出现；背景演员不作归属。可靠非社交 NPC 只展示角色资料，不伪造好感信息。
- 首页保留已验收的搜索框，将右上原解锁位置替换为事件目录入口；按钮采用融入书页的纸纹细边，不保留底部目录按钮。画廊内移除解锁入口；用户追加要求本版提供 GMCM 调试开关，沿用当前存档解锁数据，退出标题/切存档不串用，回放中不修改，GMCM 保存时提交、取消不提交。角色相册及全局目录提供全部、好感、普通、流程筛选及地点筛选。来源完全相同才合并展示，详情仍指向精确资产身份。
- 目录沿用已确认 v3 预览：角色左页资料、右页三种事件标签和六张卡；全局左页搜索/类型/地点、右页六张事件卡。首页按钮仅细边装饰，不填充异色纸纹。选择来源在当前目录内完成，详情返回保留筛选、页码和焦点。
- 监听 SMAPI AssetReady，仅记录 Data/Events 名称。目录按需读取当前内容管线，失效后重读，退出存档清空观察集。补采没有对应已存在地点的资产只读，不推测地点、不执行原版或第三方前置判定。
- 不解析全部 CP 包，不绕过 When，不覆盖节日、FarmEvent、TriggerAction 或任意 C# 事件。不新增 CP 依赖。
- 原身份、封面、历史及存储 schema 保持。用户最新明确：本版同步支持可靠地点、完整脚本且通过兼容检查的普通事件回放，包含无 NPC 归属事件；已观看或 GMCM 解锁仍作为播放入口条件。只有完整性及兼容验证通过才可播放，不因展示关联而自动开放。修正角色详情旧路径遗漏只读条件状态的问题。
- 新增普通事件兼容策略检查原版演出指令及全部引用分支，拒绝第三方命令委托、任意 action、特殊结束/跳过后果、无法确认的地点或演员。事件详情解释只读原因；启动时重新核对。新 Ordinary 回放复用现有备份、存档保护和恢复，并在同一保护类集中 Prefix Farmer.NotifyQuests，阻止原版 Speak 推进真实任务；无此补丁仅恢复 Quest 引用不能撤销任务内部变化。该补丁仅新增普通回放活跃时生效，不改自然事件或旧回放。多人继续禁用回放；Harmony 方法签名变动会禁用回放并记录错误。

验证：关联/分组/来源隔离/观察集与缓存 focused checks；目录与条件入口集成；12 语言键和占位符一致、游戏字体布局渲染；构建与必要总检查。真实 CP 切换、存档切换、鼠标/键盘/手柄导航及回放隔离标注实机结果或待实测。开发包可交付，未授权本版正式发布。
