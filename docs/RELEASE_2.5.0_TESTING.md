# 2.5.0 开发包实测

本包是待玩家实测的开发版本；不能以编译、隔离程序集运行或静态截图代替加载存档实测。未发布 main / GitHub Release / Nexus。

1. 加载常用单人存档，打开画廊。右上应为纸纹透底的“事件目录”，画廊中不再有解锁按钮。首页搜索角色/ID，返回仍停在原角色。
2. 角色相册切换全部/好感/普通；从目录按类型、地点、ID 或 NPC 搜索。打开多来源事件，翻到非第一页再进详情，返回后核对原来源页、事件页、筛选和焦点。鼠标滚轮及手柄分别试一次。
3. 打开 GMCM，开启“解锁画廊（当前存档）”并保存。关闭后恢复普通限制，实际好感和已观看记录不变。仅勾选后退出不保存应不生效；GMCM 的重置按原生行为立即保存默认值。退出标题再换存档，确认开关不串用。
4. 选择一个已观看或调试解锁、具有回放入口的普通事件。分别完成一次和跳过一次，确认回到原位置、原时间/天气，任务进度、物品与已观看记录没有增加。可在回放中拍照并设置该具体来源的封面。
5. 缺少地点/脚本片段或含未支持指令的事件应显示不可回放原因；解锁开关不能绕过该限制。条件详情、前置跳转及封面管理仍可使用。
6. 若使用 CP：测试确实随存档状态切换的事件，重新打开画廊，确认只显示当前生效内容；未生效的 CP 分支不会被强行加载。启用 DebugDiagnostics 后可提供 `catalog-latest.json` 和 `replay-compatibility-latest.json`，两份诊断用于分别定位发现/关联及回放限制。

重点：完整目录只包含当前已发现的 `Data/Events` 定义，不宣称覆盖未加载 CP 分支、节日、FarmEvent 或任意 C# 事件。无定位的补采不运行原版条件探测。
