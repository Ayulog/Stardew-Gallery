# 2.2.0 Delta：回放截图与封面

基线 `26cfd551e2b8a96390d99eca5d53659ae714050d`。分支 `feature/2.2.0-event-screenshots`。状态：开发与自动/离线验证完成，按用户指示继续 2.3.0，最后一起实测；未 CLOSED / 未正式发布。

用户将截图提前为 2.2.0，详情导航顺延为 2.3.0；已确认首版仅画廊回放手动截图、按存档分开保存。

## 本轮变化

- 回放画面增加原版相机图标按钮，默认 F8 / 手柄左肩，可通过 GMCM 改键。捕获当前世界视野，不含对话、HUD 和画廊控件；不截图全地图、不自动拍摄。
- 事件详情缩略图打开截图管理：大图查看、前后浏览、设为封面、恢复默认、移除（归档）。第一张自动成为封面；后续截图不覆盖已选封面。相册和详情共用更新后的封面，缩放保持比例。
- 使用 `SaveProfileKey`（农场与玩家 ID）及规范化 EventIdentity 隔离目录。PNG 与版本化索引保存在本 Mod 的 `event-photos/`，不写游戏存档或已有历史数据库。索引原子替换并保留旧版；移除归档文件，文件坏/丢失回退默认。
- 有界纹理缓存，菜单关闭/回标题释放；读取与编码纹理在游戏线程完成。捕获请求绑定当前回放事件对象及存档，事件结束/还原/切换存档取消请求。
- 新文案维护 12 locale；使用游戏自带相机图标与现有按钮，不引入外部素材/依赖。安装更新保留 `event-photos/`。

## 实现边界

使用 SMAPI `RenderedWorld` 及当前 RenderTarget 读取已绘制场景；已核对本机 SMAPI 4.5.2/游戏绘制顺序，世界绘制早于 HUD/对话。不用系统截图、不新增 Harmony、不改原版渲染状态或暂停回放。

ReplayCoordinator 仅提供当前正在演出的事件对象的只读访问；原有启动、保存保护、环境注入、速度、恢复流程不变。AST/evaluator、候选选择、解锁、历史采集保持不变。

## 验收

- focused 存储检查：事件/存档隔离、首封面与替换/恢复默认、归档、重启、索引/图片损坏和未来版本保护、路径检查；接入 PersistenceChecks。
- Checks + PersistenceChecks + Release build；真实 RenderTarget 截图读取/PNG、缩略图比例和缓存回收的隔离验证。
- 新管理界面及原版字体 12 locale 检查，窗口缩放和手柄按钮导航。
- 玩家单人：回放捕获正确画面、拍摄后继续回放、相册/详情封面即时更新、两存档与重启恢复、替换/移除/恢复默认。正式发布前完成相关实测。

## 验证结果

- Release build：0 warning/error；Checks、PersistenceChecks PASS。新截图存储覆盖存档/资产/ID 隔离、重启、替换、恢复默认、归档、丢失图片、损坏索引回退、未来 schema 只读保护及路径边界。
- 使用本机 MonoGame/游戏 DLL 的独立验证：直接从正在绑定的世界 RenderTarget 读取并存 PNG，回读像素与捕获前完全一致；后绘制的模拟 HUD 不进入 PNG；事件结束取消请求；封面和预览纹理释放；生产菜单设置/默认/移除及手柄页底焦点操作通过。
- 12 locale 的 48 个按钮标签字体检查通过，生产截图管理菜单两分辨率共 24 图，另 3 张空状态；中文/韩文/匈牙利文目视无压线。离线样例不是实机事件截图验收。
